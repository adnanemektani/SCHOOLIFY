# Schoolify study method

Schoolify helps learners turn curiosity into practical skills through short, repeatable study loops.

## The study loop

1. **Clarify** — rewrite the topic as a question you can answer.
2. **Retrieve** — recall what you already know before opening a resource.
3. **Explain** — teach the idea in your own words and in one minute.
4. **Apply** — build, calculate, compare, or explain a concrete example.
5. **Review** — return after one day, one week, and one month.

## Active recall

Close the notes and answer these prompts:

- What is the definition in one sentence?
- What is one example and one non-example?
- What would change if one condition were removed?
- Can I explain this without using the source vocabulary?

Active recall is more useful than rereading because it makes the gaps in memory visible.

## A weekly study plan

- Monday: understand the core concept.
- Tuesday: practise with a small example.
- Wednesday: explain the concept to someone else.
- Thursday: solve a short challenge and check the solution.
- Friday: create a one-page summary and a five-question quiz.
- Weekend: revisit mistakes and connect the topic to a real project.

Use a 25-minute focus block followed by a five-minute break. Keep the goal specific: “explain three types of neural network” is better than “study AI”.

## Feedback loop

After a quiz, classify each error:

- **Concept gap**: the rule or definition was not understood.
- **Attention gap**: a detail was missed.
- **Method gap**: the right idea was not turned into a procedure.
- **Expression gap**: the answer was correct but unclear.

Fix the first two with retrieval, the third with a worked example, and the fourth by rewriting the answer.
